ZBLS and LSLL

ZBLL needs oriented edges. ZBLS gets them for you while you insert the last pair, so every solve ends in a ZBLL case.

What ZBLS is

ZBLS (ZB last slot) inserts the last F2L pair and, at the same time, orients the four last-layer edges. The result is a solved F2L with a cross of the top colour on top, which is always a ZBLL case.

Without it, the edges are only oriented by luck, about 1 solve in 8. So ZBLS is what turns ZBLL from an occasional bonus into something you use every solve.

How the cases are organised

ZBTrain has 302 ZBLS cases, grouped by the F2L case they come from (F2L 1 to F2L 41). Within each F2L case, the variants differ in which last-layer edges are flipped. So F2L 12-3 is "F2L case 12, edge-orientation variant 3".

Many of them are a normal pair insert with a small change, so if you know your F2L cases, a lot of ZBLS feels familiar.

ZBLS vs VHLS

Both orient the last-layer edges while you solve the last slot, so they often get mixed up. They're not the same set:

  • VHLS (Vandenbergh-Harris Last Slot, from the VH method) is 32 algs for the few F2L cases where the pair is already made, or one move from being made. You first set the pair up into one of those cases, then the VHLS alg inserts it and orients the edges.
  • ZBLS covers every last-slot case (302 in ZBTrain), wherever the corner and edge are. There's no setup step: you recognise the case and do one alg.

So VHLS is a small subset of ZBLS. It's not especially efficient on its own, since setting up the pair costs moves, but it's a common stepping stone: you already make pairs in your F2L, so you can start orienting edges in your solves right away.

When to learn ZBLS

It's recommended to learn ZBLS as soon as possible, or once you're comfortable with ZBLL.

  • You use it every solve. Every solve has a last slot, but ZBLL only comes up when the edges are oriented. So the ZBLS you learn gets practised in every solve.
  • It unlocks ZBLL. Once ZBLS is in your solves, every solve ends in a ZBLL case, so all the ZBLL you've learned gets used.
  • A common plan: learn the VHLS cases and the "both in slot" cases (corner and edge already in the slot) while you're learning T, U and L ZBLL, then fill in the rest.

How long it takes

ZBLS has 302 cases, but they come in 41 sets (one per F2L case), and a lot of each set builds on F2L you already know. So it usually goes faster per case than ZBLL:

  • At one F2L set every 1–2 days, a pace that has worked for cubers who've learned it all, that's roughly 2 to 3 months.
  • At the ZBLL pace of 12 cases a week, it's about 6 months.

As with ZBLL, what matters most is coming back every day and reviewing what you've learned.

Which ZBLS cases to learn first

There's no single right order. These are the approaches cubers who've learned full ZBLS describe:

Connected pairs first

Start with the cases where the corner and edge are already paired up. You probably know a few algs already and can use them in solves straight away.

Your worst cases first

Start with the F2L cases you find awkward with normal F2L. That's where solving the last slot and the edges in one look saves the most.

Mostly random

If you're sure you'll learn all of it, the order matters less. Learning cases from different families keeps them from blurring together.

One set at a time

One F2L case (its edge-orientation variants) every day or two is a pace that's worked for people. When you're about a quarter through one set, it's fine to start the next.

Space out look-alike cases

Whatever order you pick, don't learn very similar sets at the same time. If you've always solved F2L intuitively, you may not be used to seeing F2L as separate "cases", and look-alikes are easy to mix up. Learn one, get comfortable, then come back for its neighbour.

F2L 19 to 22 all have the same corner, oriented and separated from its edge. Only where the edge sits, and which way it faces, changes. Space these out.

Practising

  • The same habits as ZBLL apply: a few cases at a time, drilled, then reviewed with spaced repetition.
  • ZBTrain's ZBLS page lets you pick exactly which cases to drill. The beginner path for ZBLS spaces look-alikes out for you: it goes F2L 1, 7, 13, 19… rather than 1, 2, 3, so cases like 19 to 22 come weeks apart. You can also choose your cases yourself on the Learn page.

Other slots and fixed angles

Your last slot isn't always front-right. Once FR feels comfortable, many ZB solvers add FL (and sometimes BR) so they don't have to rotate or set up the pair first.

  • Train other slots: on ZBTrain's ZBLS page, tick FR, FL, BR or BL under Slots. Each case comes up in every slot you tick, with algs for that slot: all 302 cases have real FL and BR algs. BL algs are still scarce, so most BL cases use a y2 followed by the FR alg.
  • Practise one angle at a time: set Edge position to a fixed spot (for example UF). The slot's edge then always starts there, so you learn to recognise each case from one angle before mixing in the others. When the edge is already in a slot, the corner starts above the slot instead.
